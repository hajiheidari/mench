# Bundled Persian font

Samim regular and bold, by Saber Rastikerdar. Unmodified files from https://github.com/rastikerdar/samim-font at commit ee3ab5791d96818e0311d82e43a4887a059507e4. The adjacent LICENSE contains the SIL Open Font License 1.1 and upstream Latin glyph attribution. Fonts are bundled locally in web/offline HTML and loaded with expo-font in the native client. No font CDN is required.
