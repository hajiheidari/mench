# Administration and session security (M15)

Administration is disabled unless server configuration ADMIN_USER_IDS lists approved account UUIDs. A client cannot nominate its role. Web/Expo account views reveal the panel only after an authenticated permission check. API enforces the allowlist on every read/action, strict schemas, origin checks and rate budgets. Never approve roles from public registration fields. No administration token is embedded in the clients.

Panel/API provide recent public IDs/names and suspension state, pending abuse/cheating/spam reports, nonsecret ledger entries, active brackets, room health/counts and audit history. Administrators can suspend1–30days, restore access, classify report decisions and cancel a lobby/running tournament. Privileged peers cannot be suspended through this endpoint. Cancelling does not fabricate match winners or alter engine/dice; already-running games can finish normally. No unrestricted chat, forced dice, financial history edits or arbitrary configuration execution.

Sensitive actions have UUID request IDs and a canonical parsed-payload hash. Transactional protected audit insertion makes identical retries idempotent and rejects changed payloads with reused IDs. Audit content cannot be rewritten/deleted; identity columns may only become null for account erasure. Production DB roles, staff onboarding/offboarding, audit retention, report triage SLA and external monitoring require operational setup before launch.

Logout disconnects game sockets authenticated by that session; other valid sessions can remain. Suspension/deletion revoke all account sessions and live account game sockets. Restoring access requires fresh login. Registered room resume also requires the same currently authenticated account; knowing a room capability cannot bypass revoked account authentication. Guest capabilities remain guest-only. Shared client clears its persisted capability/public game view on revocation. Revocation is local to the single authoritative API process; multi-instance deployment is unsupported. Socket expiry enforcement is subsequent hardening work.

PostgreSQL tests cover roles/forged commands, live session-only versus all-session disconnect, capability binding, suspended login, immutable/idempotent audit, report decisions, live bracket cancellation, fresh login, account erasure and shared GameClient clearing. Admin UI is compiled in web/native exports; no privileged browser/device acceptance is claimed. Ordinary eight browser flows and two platform flows remain regression checks.
