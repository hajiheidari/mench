# Mobile development (M9)

Expo shares engine, protocol, game client, board geometry, localization and portable dice verifier with web. Local 2/3/4-player practice, room creation/join, quick match, reconnect, proof verification and the same email profile API are implemented. Native bearer tokens/room capabilities use Expo SecureStore; Expo web uses per-tab sessionStorage. Default development endpoint is loopback; set EXPO_PUBLIC_API_URL to the reachable backend before device builds. Production must use HTTPS.
Android/iOS/web JS exports passed. Real Chromium platform test joined a desktop match from the Expo browser UI and independently verified the roll. This does not substitute for device execution. iOS native compile requires macOS/Xcode; .github/workflows/native.yml defines a manually triggered unsigned simulator build and Android development build. Workflow has not been run remotely. Do not spend CI quota, publish or sign for stores without authorization.
Generated android/ios trees are ignored; app.json and locked dependencies are source of truth. Application identifiers com.mench.game are provisional and must be reviewed before store distribution. Android template uses the generated development/debug keystore for local release-variant testing; such an APK is never a production/store release. No signing credentials are committed.
Cloud SDK: official Google repository metadata/checksum verified; command-line tools 19.0 used because rolling latest installs outside writable directories. SDK36/build-tools36.0.0/NDK27.1.12297006 selected from RN's version catalog. JDK17/JRE (required by the React Native Gradle plugin) extracted from signature-verified Debian packages into /workspace/mench-toolchains. Gradle9.3.1 checksum fetched from official source and set in generated wrapper. Java truststore augments existing CA roots with injected proxy CA, preserving TLS verification. Build uses four workers and ARM64 architecture.

Local Android Gradle compilation passed the plugin/toolchain phase but downloading react-android 0.86.3 is blocked: Maven redirects to repo.reactnative.dev, which returns HTTP 403 in this environment. That official domain was added to the saved network draft; it must be applied in environment settings before retrying. No APK exists yet. iOS native compilation remains unrun on Linux.
