# Cafe Bazaar listing (Persian)

**Name (نام برنامه):** بازی منچ دوستانه

**Short description (توضیح کوتاه، حداکثر ۸۰ نویسه):**
🎲 منچ نوستالژیک؛ آنلاین با دوستان، رقابتی یا آفلاین با ربات 🤖

**Category (دسته):** بازی › فکری / تخته‌ای — رده سنی: همه (۳+)

**Full description (توضیحات):**

🎲 همون منچ نوستالژیک بچگی، حالا روی گوشیت!
قرمز 🔴 سبز 🟢 زرد 🟡 آبی 🔵 با همون قانون‌های قدیمی که دور سفره و کنار خانواده بازی می‌کردیم.

👫 با دوستات آنلاین بازی کن
یه اتاق بساز، لینکش رو تو واتس‌اپ یا تلگرام بفرست و تمام! دوستت حتی بدون نصب برنامه، از مرورگر هم می‌تونه بیاد تو بازی.

🌍 بازی آنلاین رقابتی
توی چند ثانیه یه حریف پیدا کن و زورت رو امتحان کن 💪

📴 اینترنت نداری؟ مشکلی نیست!
با ربات 🤖 (سه سطح آسون، معمولی و سخت) یا دور هم با یک گوشی، دو تا چهار نفره بازی کنید.

🪙 کلی سکهٔ رایگان
🎁 هر روز ۲۰ سکهٔ جایزه
🏆 ۱۰ سکه برای هر برد آنلاین و ۵ سکه برای برد مقابل ربات
📺 هر تبلیغ = ۲۰ سکهٔ رایگان (کاملاً اختیاری)

🎨 طرح‌های خاص و ایرانی
✨ تاس‌های کهکشان، مرمر سبز، تراورتن، لاجورد، فیروزهٔ نیشابور، مس چکشی و طلای حکاکی
🪵 صفحه‌های چوبی، شب کویر، فیروزه‌کوبی، کاشی اصفهان و خاتم‌کاری
♟️ مهره‌های شیشه‌ای، مسی و طلایی

📜 قانون‌های کلاسیک
• با ۶ مهره وارد بازی می‌شه و یه تاس جایزه می‌گیری 🎉
• سه تا ۶ پشت هم؟ نوبتت می‌سوزه 😅
• روی مهرهٔ حریف بشینی، می‌فرستیش خونه! 🏠
• خونه‌های ستاره‌دار ⭐ امن هستن.

✅ تاس منصفانه
تاس هیچ‌وقت دستکاری نمی‌شه؛ در بازی آنلاین هر پرتاب قابل بررسیه. خرید طرح‌ها فقط ظاهر بازی رو عوض می‌کنه، نه شانس رو.

🔒 بدون ثبت‌نام
نه حساب کاربری، نه شماره تلفن. فقط یه اسم انتخاب کن و بازی کن!

همین الان نصب کن و یه دست منچ با رفیقات بزن! 🎲🔥

**What's new 1.1.0 (تغییرات این نسخه):**
صفحهٔ «سکهٔ رایگان»، سکه برای بردن بازی، تاس‌های جدید (کهکشان، مرمر سبز، تراورتن، لاجورد و…)، صفحهٔ چوبی تازه، بازی آفلاین بدون اینترنت و پیام واضح وقتی اینترنت قطع است.
